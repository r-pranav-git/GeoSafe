# GEOSAFE

**A Machine Learning Framework for Clustering-Based Crime Hotspot Detection and Women's Safety Risk Analysis**

## 📌 Overview

GEOSAFE is a Machine Learning-based crime analysis system that identifies crime hotspot regions using **K-Means Clustering** and predicts location-wise safety risk using multiple **classification algorithms**.

The project aims to support proactive women's safety by analyzing historical crime data and providing insights into high-risk areas.

---

## 🎯 Objectives

- Analyze historical crime data for pattern identification.
- Detect crime hotspot regions using K-Means Clustering.
- Predict safety risk levels using multiple Machine Learning algorithms.
- Compare classifier performance using standard evaluation metrics.
- Support proactive decision-making for women's safety.
